# Záznam nezávislého review

- Reviewed PR: URL cílového PR.
- Head commit SHA: přesný kontrolovaný commit.
- Implementující model: identifikátor a zdroj runtime metadat / explicitní konfigurace.
- Reviewující model: identifikátor z konfigurace spuštění reviewera.
- Specifikace a rozsah: odkaz, base branch a posouzený diff.

## Findings

Pro každý nález: závažnost, soubor a místo, reprodukce nebo důkaz, dopad a doporučená oprava. Pokud kontrola proběhla bez nálezů, napiš „No findings“.

## Validation results and limitations

Skutečně provedené kontroly a výsledky; převzaté výsledky implementátora označ jako převzaté. Uveď neprovedené kontroly a jejich dopad na verdikt.

## Verdict

Po dokončené nezávislé kontrole vyber approved nebo changes requested. Nedostupného reviewera oznam jako neprovedené review mimo tento dokončený záznam; nevytvářej fiktivní schválení.

## Persistence

Po zveřejnění doplň URL/ID komentáře nebo review v cílovém PR a způsob ověření. Air-local komentář ani chat nejsou samy důkazem uložení do PR.
